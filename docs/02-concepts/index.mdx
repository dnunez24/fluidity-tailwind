Fluidity scales CSS properties smoothly across viewport or container size using pure CSS `calc()`.
This section breaks down how the math works, explains the three curve types (linear, exponential, logarithmic) and when to reach for each, and shows you how to configure the scaling bounds and curves for your design.

Whether you're setting up a responsive typography scale or container-scoped spacing, these concepts apply identically across all 11 utility families.
