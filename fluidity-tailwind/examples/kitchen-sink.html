Configuration: lower / upper bounds

Same f6y-p-2/8 utility, three different ramps. f6y-lower-* / f6y-upper-* accept a breakpoint name, a container size, or an arbitrary length.

default (lower: sm 40rem, upper: 2xl 96rem)
f6y-lower-[20rem] f6y-upper-[50rem] (finishes early)
f6y-lower-lg f6y-upper-[120rem] (starts late, finishes later)

Breakpoint variants

Fluidity utilities are ordinary Tailwind @utility rules, so every built-in variant works unmodified: below md the box ramps 2 → 8; at md and up the same element switches to a wider 8 → 32 ramp. Still fully fluid either side of the breakpoint — the variant swaps the range, not a fixed value.

Arbitrary & theme values

f6y-p-[1rem]/[3rem] (both arbitrary)
f6y-p-2/[3rem] (mixed scale + arbitrary)
f6y-w-xs/lg (container-scale theme keys)
